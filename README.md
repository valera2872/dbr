# ДБР

Интерактивные детективные расследования.

Первое дело: **«Номер 314»**.

## Текущая версия

`v0.1 — engine shell`

Реализовано:

- стартовый экран дела;
- четырёхшаговый пролог;
- штаб расследования;
- вкладки «Дело», «Материалы», «Люди», «Версии», «Хронология»;
- загрузка сценария из JSON;
- разблокировка материалов по условиям;
- фиксация фактов и важных улик;
- автоматическое локальное сохранение;
- базовая offline/PWA-оболочка;
- GitHub Pages deployment workflow.

## Локальный запуск

```bash
npm install
npm run dev
```

## Производственная сборка

```bash
npm run build
npm run preview
```

Разработка ведётся поэтапно: сначала серый сценарный прототип и универсальный движок, затем визуальное оформление и AI-допросы.
