# ДБР

Интерактивные детективные расследования.

Первое дело: **«Номер 314»**.

## Текущая версия

`v0.2 — locked room`

Реализовано:

- стартовый экран и четырёхшаговый пролог;
- штаб расследования;
- вкладки «Дело», «Материалы», «Люди», «Версии», «Хронология»;
- загрузка сценария из JSON;
- интерактивный осмотр номера 314 по отдельным зонам;
- временная шкала коридорной камеры с проверочным вопросом;
- первичные допросы четырёх участников;
- открытие новых вопросов после изучения улик;
- промежуточный отчёт по первому акту;
- сюжетные ворота по найденным фактам;
- фиксация фактов и важных улик;
- автоматическое локальное сохранение;
- базовая offline/PWA-оболочка;
- публикация через GitHub Pages.

## Контрольная точка v0.2

Игрок должен самостоятельно:

1. исключить окно;
2. установить, что основная дверь после 23:50 не открывалась;
3. обнаружить признаки конфликта;
4. понять, что телефон оставлен у лифта намеренно;
5. сделать вывод о другом пути проникновения.
